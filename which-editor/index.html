Which editor do I use?

Transitrix Studio previews live in VS Code, Cursor, VSCodium and Windsurf, plus JetBrains IDEs. Without Studio, any editor and the CLI still work.

Published 13 August 2026.

Transitrix Studio is the reference editor extension — install it once and every Transitrix notation renders live as you type, in whichever of those editors you already use.

If you'd rather not install an extension, or your editor isn't one of the ones above, you can still author Transitrix files by hand in any text editor and validate them with the CLI. You lose the live preview, not the ability to model.

Installation options and the one-prompt scaffold are on the install & start page.
