The strategy and behaviour layers

Two units complete the Transitrix stack — Transitrix DSM and Transitrix Swarm. Neither is open today: not a download, not a repository to clone.

Not open. There is no build to install and no repository to clone for either unit, and no date set for that to change. The way to see either working today is a conversation.

Transitrix DSM — the strategy layer

Dynamic strategy management that operates on the Transitrix model — a strategy that updates as the enterprise model changes, instead of a document that goes stale the week it's approved. It reads the same text-native model that the methodology defines and Transitrix Studio renders, and keeps strategy legible alongside it. This is the future commercial flagship of the initiative. More on Transitrix DSM →

Transitrix Swarm — the behaviour layer

A research platform for modelling what agents do inside a Transitrix-described enterprise — the behaviour layer of the stack, one step beyond describing structure and strategy into describing action. It is in narrative today, not in active development.

Where this sits

The methodology says how to describe an enterprise as text. Transitrix Studio renders that text as diagrams you can read, review, and version. DSM and Swarm are the two layers that act on the same model once it exists — one keeping strategy current, the other exploring what agents do inside it. Neither stands apart from the open foundation; both depend on it.

See it work

Both run against real models internally today. If you want to see either working, the way to do that is a conversation — reach out at hello@transitrix.com.
