# How work is filed for this repository

Work for `transitrix.github.io` is filed in the [transitrix-hq](https://github.com/transitrix/transitrix-hq) repository, not in this repository's issue tracker.

## Where to file work

Open an issue in [transitrix-hq](https://github.com/transitrix/transitrix-hq) with the label `proj:transitrix-site`. Work filed elsewhere will not be seen or acted upon.

## Standing rules

The principles and mechanics governing work on this repository are documented in `CLAUDE.md` (gitignored, local). An agent working here reads those rules before acting, rather than inferring them from this file or from prior work.

This repository is publicly hosted. Commit messages, PR titles, and issue comments are visible to readers.
